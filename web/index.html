ADD A LITTLE SUNNY.

          

            Run the install command inside your app’s folder, then import the stylesheet. A global
            npm install does not connect the font to your project.
          

          
import "@sunnyai/sunny-marker/css";

          

            Using Next.js?
            
import { SunnyMarker } from "@sunnyai/sunny-marker/next";

            

              Use SunnyMarker.className on your note, or
              SunnyMarker.variable for a CSS variable.
