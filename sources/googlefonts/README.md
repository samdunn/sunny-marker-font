# Google Fonts designer profile

`catalog/designers/samdunn/` is the profile prepared for the Sunny Marker
onboarding package. The spelling matches the font metadata and links to
[samdunn.org](https://samdunn.org).

Sam supplied and approved the portrait for this profile. Google's `gftools
add-designer` helper resized the supplied square image to 300 × 300 pixels;
the packaged PNG contains no embedded metadata. The font's OFL does not grant
separate reuse rights to the portrait.

`make submission` includes the profile beside `ofl/sunnymarker/` in the review
archive. Google requests a separate designer-profile PR during onboarding.
Preparing these files does not register a profile with Google.

[Google's profile requirements](https://googlefonts.github.io/gf-guide/profile.html)
